Пять режимов в одном репозитории

Новые страницы: /miospore-key/akinator/ и /miospore-key/bookkey/. Это готовые HTML-файлы: сервер базы данных и установка библиотек посетителям не нужны.

1. Распакуйте обновление

Используйте miospore_key_github_update.zip. В корне архива:

index.html                    ← 01: свободный фильтр
database/
    index.html                ← 02: каталог
    data.json
databasesimplified/
    index.html                ← 03: таблицы SQLite
    data.json
akinator/
    index.html                ← 04: да / нет / не знаю
bookkey/
    index.html                ← 05: ключ из монографии
comparison.json               ← результаты проверки алгоритма
GITHUB_UPDATE.html            ← этот гайд
.nojekyll

Сохраняйте папки и пути. Все пять страниц называются index.html, но лежат в разных папках. В репозитории не нужна дополнительная обёртка miospore_key/. Сам ZIP загружать вместо файлов не нужно.

2. Загрузите файлы на GitHub

  1. Откройте свой репозиторий miospore-key, вкладку Code, ветку публикации (обычно main).
  2. Выберите Add file → Upload files. Перетащите содержимое распакованного архива, включая четыре папки. Дождитесь загрузки.
  3. Проверьте пути новых файлов: akinator/index.html и bookkey/index.html. Обновите и три прежних HTML: в них добавлены ссылки на новые режимы.
  4. Напишите сообщение Add Akinator and monograph key. Сохраните изменения в ветку публикации, если это разрешено. При создании отдельной ветки создайте pull request и объедините его в ветку публикации.

Каждый HTML этого пакета меньше 25 MiB — лимита загрузки одного файла через браузер. Официальная инструкция GitHub по загрузке.

3. Дождитесь обновления сайта

Если Pages уже работает, настройки обычно менять не требуется. Для публикации из ветки: Settings → Pages → Deploy from a branch, нужная ветка и /(root). При публикации из /docs размещайте файлы внутри этой папки. Если настроен собственный Actions workflow, сохраняйте используемый им каталог.

После commit в ветку публикации сайт обновляется автоматически. Во вкладке Actions дождитесь успешного запуска Pages. Настройка источника публикации.

Адреса после публикации (замените ВАШ-ЛОГИН и имя репозитория на свои):

Если видна старая версия, нажмите Ctrl + F5. При 404 проверьте имя папки в нижнем регистре, наличие в ней index.html и завершение публикации.

Локальная пересборка

Полный miospore_key.zip содержит исходники. Для пересборки прежних страниц из включённых снимков данных:

python source/rebuild.py
python source/database/rebuild.py
python source/databasesimplified/rebuild.py

Для новых режимов используется source/key-modes/data.json: матрица, родовые диагнозы, переходы ключа и восемь встроенных сканов. book-key.txt — читаемая расшифровка ключа. После правки интерфейса пересоберите обе страницы:

python source/key-modes/rebuild.py

Если меняете исходные данные, согласуйте снимок новых режимов с матрицей и повторите оценку node source/key-modes/evaluate.cjs, затем пересборку. Диагнозы, матрица и авторский ключ — отдельные слои: изменение SQLite само по себе не меняет кодировку признаков и маршруты.

Каталог и таблицы можно обновить из SQLite:

python source/database/rebuild.py --sqlite "C:\путь\miospores.sqlite"
python source/databasesimplified/rebuild.py --sqlite "C:\путь\miospores.sqlite"

Затем загрузите готовые HTML по тем же путям. Исходная SQLite не изменяется при работе сайта.
