Как загрузить новую версию

У вас уже есть репозиторий miospore-key. Новая страница каталога будет открываться по адресу https://ВАШ-ЛОГИН.github.io/miospore-key/database/. Табличный просмотр исходных записей будет по адресу https://ВАШ-ЛОГИН.github.io/miospore-key/databasesimplified/. Адрес определителя: https://ВАШ-ЛОГИН.github.io/miospore-key/.

1. Подготовьте файлы

Распакуйте miospore_key_github_update.zip. Внутри готовый набор для загрузки:

index.html               ← обновлённый определитель
database/
    index.html           ← новая страница базы
    data.json            ← снимок каталога
databasesimplified/
    index.html           ← таблицы как в DB Viewer
    data.json            ← снимок таблиц и представлений
GITHUB_UPDATE.html       ← этот гайд
.nojekyll                ← служебный пустой файл

Загружайте содержимое распакованного архива в корень репозитория. Папки database и databasesimplified переносите целиком: их файлы index.html должны остаться внутри.

У трёх страниц одинаковое имя файла. Корневой index.html — определитель; database/index.html — каталог; databasesimplified/index.html — исходные таблицы. Сохраняйте эти пути. ZIP нужно распаковать: GitHub Pages не распаковывает загруженные архивы.

2. Загрузите через браузер

  1. Откройте свой репозиторий miospore-key, вкладку Code. Перейдите в ветку, из которой опубликован сайт; по предыдущему гайду это main.
  2. Нажмите Add file → Upload files.
  3. Перетащите корневой index.html, папки database и databasesimplified, GITHUB_UPDATE.html и .nojekyll в область загрузки. Дождитесь загрузки всех файлов.
  4. В списке проверьте пути: index.html, database/index.html и databasesimplified/index.html. Путь miospore_key/database/index.html внутри репозитория здесь не нужен.
  5. В поле сообщения напишите Add SQLite table viewer. Для своего обычного репозитория выберите Commit directly to the main branch, если этот вариант доступен, и нажмите Commit changes. Если доступно только создание ветки, завершите Propose changes, затем создайте и объедините pull request.

GitHub принимает через браузер файлы до 25 MiB каждый; все три HTML-страницы этого пакета укладываются в лимит. Документация загрузки файлов.

3. Проверьте публикацию

  1. Откройте Settings → Pages. При публикации из ветки должны быть выбраны Deploy from a branch → main → /(root). Если это уже настроено, повторно сохранять настройки не нужно. Если сайт публикуется из /docs, загрузите файлы в эту папку.
  2. Откройте вкладку Actions и дождитесь зелёной отметки у нового запуска публикации Pages. Если запуск красный, откройте его и посмотрите сообщение об ошибке.
  3. Откройте адрес сайта из Settings → Pages и добавьте в конец databasesimplified/ для исходных таблиц или database/ для каталога. В меню определителя есть ссылки «Каталог» и «Таблицы».
  4. Если видна старая версия, обновите страницу сочетанием Ctrl + F5. При 404 проверьте наличие databasesimplified/index.html именно в папке публикации, нижний регистр имени и завершение запуска Actions.

После сохранения изменений в ветке публикации GitHub Pages обновляет сайт автоматически. Настройка и проверка публикации.

Следующие обновления данных

Повторите загрузку изменённых HTML-файлов по тем же путям и создайте новый commit. Для просмотра пользователям достаточно готовых HTML-страниц; SQLite устанавливать не нужно.

Если вы редактируете сами данные, используйте полный пакет miospore_key.zip, где есть исходники и JSON. После изменения character_matrix.json выполните из его папки:

python source/rebuild.py
python source/database/rebuild.py

Табличный просмотрщик использует собственный снимок исходной SQLite. Для пересборки его текущих данных:

python source/databasesimplified/rebuild.py

Для обновления каталога из изменённой SQLite-базы:

python source/database/rebuild.py --sqlite "C:\путь\miospores.sqlite"
python source/databasesimplified/rebuild.py --sqlite "C:\путь\miospores.sqlite"

Затем загрузите пересобранные HTML-файлы. Матрица признаков ведётся отдельно: изменение SQLite не пересчитывает автоматически разметку определителя. Визуальная страница показывает снимок данных, встроенный в HTML.
